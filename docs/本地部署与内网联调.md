# 本地部署与内网联调

本文用于补齐合同清单 `5.4 本地部署与内网联调` 的交付材料，覆盖：

- 前端容器化部署
- 自托管 Supabase 对接
- Edge Functions 密钥配置
- 数据库备份与恢复
- Storage 备份与恢复
- 内网联调检查

## 1. 目录说明

- `Dockerfile`
  用于构建前端生产镜像。
- `docker-compose.yml`
  用于在服务器上启动前端容器。
- `.env.example`
  提供前端、数据库、Storage、Edge Functions 的环境变量模板。
- `scripts/ops/backup-postgres.sh`
  备份 PostgreSQL 数据库。
- `scripts/ops/restore-postgres.sh`
  恢复 PostgreSQL 数据库。
- `scripts/ops/backup-storage.sh`
  备份 Supabase Storage 文件。
- `scripts/ops/restore-storage.sh`
  恢复 Supabase Storage 文件。
- `scripts/ops/check-local-stack.sh`
  执行本地联调健康检查。
- `scripts/ops/check-ai-endpoints.sh`
  检查本地大模型 / ASR / OCR 地址是否可访问。

## 2. 前置条件

服务器建议环境：

- Ubuntu 22.04 或更高
- Docker 24+
- Docker Compose v2
- `pg_dump` / `pg_restore`
- `curl`

如果 PostgreSQL 运行在容器中，也可以在宿主机安装 `postgresql-client`：

```bash
sudo apt-get update
sudo apt-get install -y postgresql-client curl
```

## 3. 前端部署

### 3.1 准备环境变量

复制环境模板：

```bash
cp .env.example .env
```

至少补齐：

```bash
VITE_SUPABASE_URL="https://supabase.example.com"
VITE_SUPABASE_PUBLISHABLE_KEY="sb_publishable_xxx"
VITE_SUPABASE_PROJECT_ID="selfhost-example"
APP_PUBLIC_URL="https://performance.example.com"
```

### 3.2 启动前端容器

```bash
docker compose up -d --build
```

默认端口：

- 宿主机 `8080`
- 容器内 `80`

如果需要挂在域名反向代理下，可由 Nginx / Caddy / Traefik 转发到宿主机 `8080`。

## 4. 自托管 Supabase 对接

本仓库默认假设 Supabase 已由独立部署完成。数据库结构请使用：

- `supabase/migrations/*.sql`

如果是新环境，建议执行：

```bash
supabase db reset
```

或在目标库按顺序执行迁移 SQL。

## 5. Edge Functions 密钥配置

下面这些函数依赖 Supabase Secret：

- `generate-report`
- `generate-rectification`
- `generate-evaluation-plan`
- `analyze-meeting`
- `transcribe-audio`
- `match-materials`
- `check-materials-completeness`
- `generate-expert-notice`
- `delete-user`
- `update-user-password`
- `check-task-deadlines`
- `match-experts`
- `rewrite-report-block`
- `amap-config`
- `preview-material`

至少要配置：

```bash
supabase secrets set \
  SUPABASE_URL="https://supabase.example.com" \
  SUPABASE_SERVICE_ROLE_KEY="sb_secret_xxx" \
  AI_API_KEY="sk_xxx" \
  AI_CHAT_BASE_URL="https://ai.gateway.lovable.dev/v1/chat/completions" \
  AI_MODEL_DEFAULT="google/gemini-2.5-flash" \
  AMAP_JSCODE="xxxxxxxx"
```

如果要按业务单独指定模型，可继续增加：

```bash
AI_MODEL_REPORT="google/gemini-3-flash-preview"
AI_MODEL_RECTIFICATION="google/gemini-2.5-pro"
AI_MODEL_EVALUATION_PLAN="google/gemini-2.5-pro"
AI_MODEL_MEETING_ANALYSIS="google/gemini-3-flash-preview"
AI_MODEL_MATERIAL_MATCH="google/gemini-2.5-flash"
AI_MODEL_MATERIAL_COMPLETENESS="google/gemini-2.5-flash"
AI_MODEL_REPORT_REWRITE="google/gemini-2.5-flash"
AI_MODEL_TRANSCRIPTION="google/gemini-2.5-flash"
AI_MODEL_EXPERT_NOTICE="google/gemini-2.5-flash"
```

如果后续切换到本地大模型 / 本地 ASR / 本地 OCR，可继续调整：

```bash
AI_CHAT_BASE_URL="http://127.0.0.1:11434/v1/chat/completions"
AI_MODEL_DEFAULT="qwen2.5:14b-instruct"
LOCAL_ASR_BASE_URL="http://127.0.0.1:8001"
DOCUMENT_EXTRACTOR_BASE_URL="http://127.0.0.1:8091"
LOCAL_OCR_BASE_URL="http://127.0.0.1:8091"
```

约定的本地接口格式：

- `LOCAL_ASR_BASE_URL/transcribe`
  请求 JSON：`{ audioBase64, mimeType, context }`
  返回 JSON：`{ transcript }`
- `DOCUMENT_EXTRACTOR_BASE_URL/ocr`（兼容旧配置 `LOCAL_OCR_BASE_URL/ocr`）
  请求 JSON：`{ fileName, mimeType, fileBase64 }`
  返回 JSON：`{ text, method, pages }`

## 6. 数据库备份与恢复

### 6.1 备份数据库

```bash
export DB_HOST=127.0.0.1
export DB_PORT=54322
export DB_NAME=postgres
export DB_USER=postgres
export DB_PASSWORD='please-change-me'

./scripts/ops/backup-postgres.sh
```

产物：

- `backups/postgres/performance-db-时间戳.dump`
- `backups/postgres/performance-db-schema-时间戳.sql`

### 6.2 恢复数据库

```bash
./scripts/ops/restore-postgres.sh ./backups/postgres/performance-db-20260629-120000.dump
```

如果不传文件，会自动选择最新一份备份。

## 7. Storage 备份与恢复

### 7.1 备份 Storage

```bash
export STORAGE_DIR=/srv/performance-supabase/storage
./scripts/ops/backup-storage.sh
```

### 7.2 恢复 Storage

```bash
./scripts/ops/restore-storage.sh ./backups/storage/storage-20260629-120000.tar.gz
```

## 8. 内网联调检查

启动前端和 Supabase 后执行：

```bash
export APP_PUBLIC_URL="http://127.0.0.1:8080"
export SUPABASE_URL="http://127.0.0.1:54321"
./scripts/ops/check-local-stack.sh
```

检查项：

- 前端首页可访问
- Supabase REST API 可访问

如已启用本地模型 / ASR / OCR，可继续执行：

```bash
./scripts/ops/check-ai-endpoints.sh
```
