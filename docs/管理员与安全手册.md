# 管理员与安全手册

本文用于补齐等保 / 审计增强相关的管理员使用说明。

## 1. 权限与安全中心

入口：

- 左侧菜单 `权限与安全中心`
- 地址：`/security-center`

可查看内容：

- 角色权限矩阵
- 用户角色分配
- 联系方式脱敏展示
- 审计覆盖范围
- 用户删除与密码重置

## 2. 审计日志

入口：

- 左侧菜单 `操作日志`
- 地址：`/audit-logs`

支持能力：

- 最近 500 条关键写操作查看
- 按表、动作、执行人搜索
- 查看变更前 / 变更后 JSON
- 导出 CSV

当前纳入审计或访问留痕的对象包括：

- `projects`
- `experts`
- `reports`
- `materials`
- `evaluation_packages`
- `work_groups`
- `work_tasks`
- `user_roles`
- `doc_templates`
- `share_links`
- `share_link_views`

## 3. 外发安全

入口：

- 报告页面中的 `安全外发分享`

支持能力：

- 设置访问密码
- 设置有效期
- 设置最大访问次数
- 强制水印
- 吊销分享链接
- 查看访问审计

访问审计记录字段：

- 访问时间
- IP 地址
- User-Agent
- 成功 / 失败
- 失败原因

## 4. 管理员操作建议

- 删除用户前先查看其业务数据影响
- 定期导出审计日志归档
- 对共享链接设置有效期与访问次数
- 对测试账号定期重置或删除
- 对生产环境仅授予必要的管理员角色
