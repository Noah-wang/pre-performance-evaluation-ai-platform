# 系统使用手册

本文用于培训项目单位、评估工作组成员和专家快速上手系统。

## 1. 角色说明

- 管理员：管理账号、角色、安全策略、模板和审计日志。
- 工作组成员：维护项目、资料、工作组、调研、会议、报告和归档。
- 专家：查看项目资料、参与会议、提交评分和意见。

## 2. 标准使用流程

### 2.1 创建评估对象

入口：

- 左侧菜单 `评估对象管理`

操作：

- 新建项目
- 选择项目类别、申请单位、主管部门、预算金额
- 关联评估指标体系

### 2.2 建立资料清单与上传资料

入口：

- 左侧菜单 `资料审核`

操作：

- 点击 `加载标准清单`
- 点击 `按指标同步`
- 对缺失资料点击 `添加文件`
- 上传后可点击 `确认指标` 或 `AI 匹配资料与指标`

说明：

- `指标证据雷达` 按指标展示哪些资料已形成证明、哪些仍缺证。
- 已进入雷达证明区的文件，不再显示在待处理资料区。

### 2.3 组织工作组与时间计划

入口：

- 左侧菜单 `工作组管理`

操作：

- 建立工作组
- 添加组长、成员、专家
- 设置任务起止时间
- 使用 `方案` 页签生成 AI 评估实施方案

### 2.4 现场调研与会议纪要

入口：

- 左侧菜单 `现场调研`
- 左侧菜单 `会议纪要`

操作：

- 现场调研页可记录地点、发现、结论、照片、录音和签字
- 会议页可录入纪要、上传材料并执行 AI 分析

说明：

- 录音转写默认可走 AI 网关，也可切换为本地 ASR。
- 会议 AI 分析会给出业务 / 管理 / 财务三类专家意见，并生成正式评估意见摘要。

### 2.5 生成报告与整改建议

入口：

- 左侧菜单 `评估报告`

操作：

- 点击 `AI 撰写`
- 在线编辑正文
- 点击 `生成整改建议`
- 勾选采纳条目后保存

说明：

- 报告、方案、会议分析已接入知识参考，会综合项目资料、历史归档报告和绩效目标库辅助生成。

### 2.6 专家打分与归档

入口：

- 左侧菜单 `专家打分`
- 左侧菜单 `结果归档`

操作：

- 录入评分或上传打分表
- 导出专家组评估意见书
- 将完整项目归档为 ZIP

## 3. 常见问题

### 3.1 为什么 AI 内容会提示“已注入资料 / 历史 / 目标”

这表示系统在生成时自动参考了：

- 当前项目已上传资料
- 已归档历史项目报告
- 绩效目标库中的高复用目标

### 3.2 为什么某些指标显示“未证明”

说明当前没有已上传且足以支撑该指标判断的文件。需要：

- 补传材料
- 或人工确认文件与指标关系
- 或重新执行 AI 匹配

### 3.3 为什么图片 / PDF 预览没有文字

若未配置 `LOCAL_OCR_BASE_URL`，系统只能直接读取 `txt / docx` 正文。配置本地 OCR 后，图片 / PDF 可返回识别文本。
